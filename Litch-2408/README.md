# Litch

Litch é um protótipo fictício de plataforma digital voltada ao universo dos jogos. O projeto reúne descoberta de títulos, catálogo, ofertas, assinatura e comunidade em uma interface moderna, responsiva e de fácil navegação.

O objetivo é apresentar uma experiência centralizada para jogadores encontrarem novos jogos, conhecerem benefícios do Litch+ e acessarem conteúdos relacionados à comunidade.

## Funcionalidades futuras

- Seleção semanal de jogos em destaque
- Catálogo com preços, descontos e informações básicas
- Banner para jogos em evidência
- Apresentação do serviço de assinatura Litch+
- Área dedicada à comunidade
- Página institucional sobre a plataforma
- Carrosséis horizontais com navegação por rolagem
- Layout responsivo para computadores, tablets e celulares
- Animações e interações visuais com suporte à preferência por movimento reduzido

## Como executar

Como se trata de um projeto estático, não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd Litch-2408
```

3. Abra o arquivo `html/index.html` no navegador.

Também é possível iniciar um servidor local com Python:

```bash
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000/html/index.html
```

## Páginas

### Página inicial

A página inicial apresenta os jogos selecionados da semana, a Game Store, o catálogo do Litch+ e os recursos da comunidade.

### Sobre

A página Sobre apresenta a proposta, a visão, os valores e os principais diferenciais da Litch.

## Responsividade e acessibilidade

A interface se adapta a diferentes tamanhos de tela. O projeto também utiliza HTML semântico, textos alternativos em imagens, rótulos de navegação e tratamento para usuários que preferem animações reduzidas.
